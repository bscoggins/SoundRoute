Before filing a bug

It speeds things up enormously if you include:

  • macOS version (Apple menu → About This Mac)
  • Mac model (e.g. "M2 MacBook Air")
  • SoundRoute version (it's in the menu bar popover, or check About in the menu)
  • Which input and output devices were selected when the issue happened
  • What you expected and what actually happened

Common questions

Why is there no audio coming through?

  • Make sure both an input and output device are selected, then click Start Routing.
  • Check that the output device's volume isn't muted in System Settings → Sound.
  • If your input device is a microphone, macOS may have prompted you to grant microphone permission. You can change that in System Settings → Privacy & Security → Microphone.

The audio sounds choppy or stuttery

  • Try stopping routing, switching to a different output device, then switching back.
  • Heavy CPU load on your Mac (large compiles, video rendering, etc.) can cause occasional dropouts.

The icon doesn't appear in my menu bar

  • If you have a menu bar manager (Bartender, Hidden Bar, etc.) the icon may be hidden. Check the overflow.
  • If the menu bar is full, macOS may hide some items. Try removing one or two.

Can I have it launch automatically?

Yes — open the menu bar popover and check Launch at login.
